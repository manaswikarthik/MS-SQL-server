Project Overview

A logistics company manages shipments, customers, carriers, hubs, employees, and delivery events. This project analyzes shipment data using SQL joins, subqueries, data manipulation, and MongoDB aggregation.

MySQL

MongoDB

SQL

MongoDB Aggregation Pipeline

INNER JOIN, LEFT JOIN, RIGHT JOIN and FULL OUTER JOIN equivalent

Subqueries using IN, EXISTS, ANY and ALL

Subquery rewriting using JOIN

The project demonstrates relational data analysis using SQL and document-based data analysis using MongoDB, including joins, subqueries, aggregations, and data manipulation.
